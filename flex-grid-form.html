Flexbox and Grid Layout Example

This project shows how to build a simple form using both Flexbox and CSS Grid.

Registration Form

What is Flexbox?

Flexbox is used for arranging items in a row or column. It is best for simple layouts like a form with vertical fields.

What is CSS Grid?

Grid is used to create page layouts with rows and columns. It is perfect for placing the form and the info section side by side.

.layout-box { display: grid; grid-template-columns: 1.2fr 1fr; } form { display: flex; flex-direction: column; }
